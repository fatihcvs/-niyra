Kontrol tarihi: 2026-09-05.

## Kaynak ve kapsam sınırları

- Güney Kıbrıs: CYQAA/ΔΙΠΑΕ program kimlikleri ve yayımlanmış ders dağılımı PDF’leri. Başarılı HTTP yanıtı tek başına geçerli PDF sayılmadı; metin/tablo okunamayan belgeler alınmadı.
- Kuzey Kıbrıs: kurumların kendi program sayfaları, ders planları ve el kitapları. Program adı, eğitim dili, derece ve süre ayrımları korundu. Ders kodundan sınıf veya dönem üretilmedi.
- Yakın Doğu sayfalarının doğrudan erişimi insan doğrulamasına takıldı. Erişim engeli aşılmadı; arama sonuçları eksiksiz müfredat yerine kullanılmadı.
- Rauf Denktaş’ın resmî program sayfasının kullandığı açık program API’si 404 döndürdü. Programların dersleri tahmin edilmedi.
- BAU Kıbrıs Mimarlık kaydında katalogdaki 4 yıllık süre ile kaynak sayfadaki 5 yıllık süre farklı olduğundan eşleşme reddedildi. İlk yıl dışındaki dersler, sayfanın yayımlanmış yıl sekmelerini besleyen veriden yalnız aynı program kimliği için alındı.
- Avrupa Liderlik Data Science sayfasında başka bir kurumun adını taşıyan ders bulundu; bu sayfa güvenilir yapılandırılmış müfredat olarak alınmadı.
- Cosmos ve Alasya için onaylı program kanıtı bulunmayan planlanan bölümler oluşturulmadı.
- Kaynaktaki farklı uzmanlık yolları tek zorunlu ders listesi yapılmadı. Belirsiz alternatif kodlar, seçmeli boşlukları, özet/toplam satırları ve çelişkili tekrarlar dışarıda bırakıldı.
- Kaynak tarihi, URL, içerik SHA-256 değeri ve PDF sayfası mevcut kayıtlarda korunur. Dönem/tür bilinmiyorsa null; tekrar açılan bir dersin dönemleri offeredSemesters alanındadır.

## Yakın bölgeler

54 yerleşke/referans kaydından 49’unun konumu biliniyor. 33 üniversitede 2.609 yakın mekân/bölge, bunların içinde 209 mahalle/yerleşim merkezi var. Mekânlar en çok 1,5 km, bölge merkezleri en çok 5 km kuş uçuşu mesafede seçildi. Kuzey/güney coğrafi sınırı kontrol edildi; bu mesafeler yürüyüş veya araç rotası değildir.

Philips, Rauf Denktaş (iki nokta), Avrupa Liderlik Gazimağusa ve University of Limassol (iki nokta) için resmî sayfalardaki harita işaretleri kullanıldı. Alasya’nın resmî sayfasındaki harita bağlantısı Bangladeş’e yöneldiği için reddedildi. Konumu bilinmeyen beş noktaya koordinat atanmadı.

## Yeniden üretim

Python 3, beautifulsoup4 ve pdfplumber gerekir. Ham kaynaklar `.sites-runtime/cyprus-expansion` altında tutulur, ürün verisine ve Git’e eklenmez. Öğrenci veya personel hesabı gerekmez.

```powershell
python scripts/academic-catalog/cyprus_research.py cyqaa
python scripts/academic-catalog/extract_cyprus_tables.py
python scripts/academic-catalog/parse_cyprus_courses.py
python scripts/academic-catalog/sync_cyprus_html.py
python scripts/academic-catalog/parse_cyprus_html.py
python scripts/academic-catalog/discover_cyprus_extra.py
python scripts/academic-catalog/parse_cyprus_extra.py
python scripts/academic-catalog/parse_cau_courses.py
python scripts/academic-catalog/parse_gau_courses.py
python scripts/academic-catalog/parse_additional_courses.py
python scripts/academic-catalog/test_cyprus_parsers.py
python scripts/academic-catalog/build_cyprus_course_catalog.py
```

Kampüs çevresi için `cyprus_research.py places` ardından `build-cyprus-place-catalog.mjs` ve `build-campus-place-catalog.mjs` çalıştırılır. İlk betik, konut araştırmasının North Cyprus sınır geometrisi önbelleğini (`.sites-runtime/housing/north-cyprus-geometry.json`) ve sürümlenen `data/cyprus-campuses-2026.json` kaynaklarını kullanır. Geometri yoksa veya açık halka içeriyorsa yayın üretimi durur.

Program düzeyindeki kalan işler: `data/cyprus-catalog-coverage-2026.json`. `partial`, `source-linked` ve `source-needed` durumları birbirinden ayrılır. Tek tek eksik kaynaklar doğrulanmadan tamamlandı işareti verilmemelidir.
